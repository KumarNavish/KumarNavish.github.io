Evidence boundary

Generated research claims only

The public release does not process real claims, send customer messages, give legal advice, calculate deadlines, decide coverage or authorize a shared playbook update. Legal mappings and generated process paths remain unapproved operational hypotheses.

Modes

  • Public: generated claims, cached runs, traces, comparisons and knowledge.
  • Researcher sandbox: OpenRouter, Nemotron, swap contracts and run downloads.
  • Expert sandbox: browser-local corrections and governance.

Architecture

A dedicated Render static site publishes the versioned master/casepath directory. OpenRouter OAuth PKCE supplies a visitor-controlled key for optional live inference. Deterministic browser code validates proposals, executes the process and derives the checklist.

Security model

  • no private-corpus files or blinded targets;
  • no embedded provider key;
  • no arbitrary agent execution;
  • immutable released knowledge;
  • browser-local reviews and caches;
  • human approval for every operational action.
